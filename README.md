# M3uPot — 本地影院

基于 **Vue 3 + Vite + TypeScript** 的本地媒体浏览工具。导入本地媒体列表 JSON 文件，以海报墙形式展示，并支持搜索、排序与分页，适合管理本地影视资源。

## 功能

- 选择本地 `.json` 媒体列表文件（点击或拖拽）进行导入
- 兼容多种字段别名：名称（`vod_name`/`name`/`title`）、播放地址（`vod_play_url`/`url`/`src` 等，支持苹果 CMS 的 `高清$url#流畅$url` 多源格式）、简介、海报、时长、发布时间
- 关键词搜索（按名称/简介）
- 按视频时长（升/降序）或发布时间（升/降序）排序
- 分页浏览，切换分页自动回到顶部
- 响应式布局，移动端紧凑化展示

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发（默认 http://localhost:5173）
npm run dev

# 类型检查 + 构建
npm run build

# 预览构建产物
npm run preview
```

## 使用说明

1. 打开页面后，点击「选择本地文件」或将 JSON 文件拖入虚线框。
2. 解析成功后，媒体以海报墙形式展示，支持点击卡片查看。
3. 顶部工具栏可按名称/简介搜索、调整每页条数、选择排序方式。
4. 底部分页可翻页、跳页；切换页面时列表自动回到顶部。

## 项目结构

```
src/
├── App.vue                 # 应用入口，挂载本地影院页面
├── main.ts                # 应用入口脚本
├── style.css              # 全局样式（仅本地影院相关）
└── components/
    └── LocalCinema.vue    # 本地影院：文件导入、搜索、排序、海报墙、分页
```

## 备注

- 媒体列表为本地文件，不涉及远程请求与跨域(CORS)问题。
- 大文件解析使用 `shallowRef` 避免对成千上万条记录做深响应式代理，降低移动端内存压力。
